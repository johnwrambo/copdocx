05 / usage rules

Small rules that keep the system truthful

Marker, layer row, popup, and printed legend should all use the same source entry and the same badge renderer.

  • Meaning first Glyph identifies meaning; color only reinforces the broad family.
  • One renderer Legends show the complete mini-marker, never a detached glyph.
  • Priority is additive Use the primary size and rank treatment without replacing the place icon.
  • Custom color changes fill Vehicle or user color may override fill; glyph and keyline retain meaning.
  • Touch beyond the art Keep at least a 44px interactive hit area around every marker.
  • Say the full meaning Accessible names include category, subject, priority, and address.
